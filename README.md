# 21vek_competition
Поисковая система — ключевой компонент качественного пользовательского опыта в e-commerce. Чтобы находить нужные товары среди десятков тысяч позиций, важно точно понимать намерение пользователя.
С помощью методов машинного обучения мне необходимо решить задачу классификации: определить, к какой категории товаров относится поисковой запрос, сделанный на сайте 21vek.by.



## 📂 Описание данных

- **train.csv** — обучающая выборка с запросами пользователей и метками категорий (`CategoryID`).
- **test.csv** — тестовая выборка с запросами без указания категорий. На этих данных проводится финальное предсказание.
- **categories.csv** — справочник всех доступных категорий товаров (`CategoryID` и `CategoryName`).
- **sample_submission.csv** — пример файла для правильной отправки предсказаний.

## ⚙️ Используемые методы

- **Очистка текста** (`clean_text`): приведение текста к нижнему регистру, удаление лишних символов и пробелов.
- **Векторизация**: использование `TfidfVectorizer` для преобразования текста в числовые признаки.
- **Модели машинного обучения**:
  - Naive Bayes (`MultinomialNB`)
  - Logistic Regression (`LogisticRegression`)
  - Random Forest (`RandomForestClassifier`)
  - Gradient Boosting (`GradientBoostingClassifier`)

## 📈 Оценка моделей

Для оценки качества классификации использовались следующие метрики:
- **Accuracy** (точность классификации)
- **Precision** (точность по классам)

Выбрана лучшая модель на основе значения Accuracy.

